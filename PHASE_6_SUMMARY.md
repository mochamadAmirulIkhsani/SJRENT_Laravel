## 📝 Quick Start Guide

### Update Company Information
1. Sidebar → Pengaturan → Company Settings
2. Edit any tab (Company Info, Contact, SEO, etc.)
3. Click Save
4. ✅ Done!

### Add Customer Testimonial
1. Sidebar → Konten Website → Testimonials
2. Click "Create"
3. Fill customer name, rating, review
4. Upload photo (optional)
5. Toggle "Approved" to publish
6. ✅ Done!

### Upload Gallery Photo
1. Sidebar → Konten Website → Gallery
2. Click "Create"
3. Upload image
4. Select category (Company/Fleet/Facilities)
5. Add title and alt text
6. ✅ Done!

### Enhance Motorcycle Listing
1. Sidebar → Master Data → Motorcycles
2. Edit a motorcycle
3. Go to "Features & Specs" tab
4. Add features (e.g., ABS, USB Charger)
5. Go to "SEO" tab
6. Add meta description
7. ✅ Done!
